# Portafolio Digital Educativo 2026 — I.E. 14787

Portafolio web renovado a partir del **Boletín Informativo 2026** de la I.E. N.° 14787 “Víctor Raúl Haya de la Torre”.

## Mejoras realizadas
- Se incorporó el contenido de los 14 apartados del boletín.
- Se amplió la sección de relación del personal con directivos, docentes, administrativos y auxiliares.
- Se incluyeron derechos y responsabilidades de estudiantes y padres de familia con más detalle.
- Se incorporó la calendarización 2026 con bloques, UD/EDA, fechas de inicio y fin.
- Se incorporaron las actividades del PAT con sus fechas.
- Se incorporó el himno y el sistema de evaluación AD, A, B y C.
- Se añadió la reseña histórica adicional de Víctor Raúl Haya de la Torre que aparece al final del boletín.
- La navegación ahora funciona por **páginas independientes dentro de la misma web**, en lugar de una sola página larga.
- Los botones **Anterior / Siguiente**, el menú superior, los puntos de navegación, la rueda del mouse y el gesto de desplazamiento permiten cambiar de página.
- Las secciones muy extensas tienen desplazamiento interno para que la información no quede cortada.
- Se mantiene la insignia institucional proporcionada.
- Se añadió el asistente estudiantil AULA, con preguntas sugeridas y respuestas contextualizadas sobre horarios, evaluación, calendario, convivencia, misión, visión y valores.
- El asistente funciona localmente sin claves ni servidor; para usar una IA generativa se debe conectar un endpoint seguro desde el servidor, sin exponer la clave en `script.js`.

## Uso
1. Descomprime el ZIP.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. No requiere servidor para funcionar.

## Estructura
- `index.html`
- `styles.css`
- `script.js`
- `assets/insignia-sullana.png` — insignia institucional enviada para la presentación.
